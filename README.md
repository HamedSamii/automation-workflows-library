# Workflow Automations That Connect the Tools a Business Already Uses

A form is submitted. The sheet updates, the CRM gets the lead, the team is notified.

> **Case study.** Source code is private. The business problem, the design decisions and the stack are documented here.

## The problem

Small businesses run on a mix of forms, sheets, CRMs and chat tools that do not talk to each other, so people become the integration layer.

## What was built

- **Form to sheet to CRM** pipelines
- **Webhook-driven triggers** between systems
- **Notifications** to the right channel at the right moment

## Stack

n8n · Make · Google Sheets · CRM APIs · Webhooks

## Status

Collection of tested workflows and integration patterns.
